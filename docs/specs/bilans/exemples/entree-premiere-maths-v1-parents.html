Forces

  1. calcul-litteral constitue un acquis solide sur lequel le parcours peut prendre appui.
  2. droites constitue un acquis solide sur lequel le parcours peut prendre appui.

Les priorités du stage

  1. En fonctions-reference, un raisonnement tenu pour juste doit d'abord être confronté puis reconstruit.
  2. En calcul-numerique, un raisonnement tenu pour juste doit d'abord être confronté puis reconstruit.
  3. La difficulté en fonctions est déjà repérée ; le parcours installera les notions puis un entraînement court.
  4. La difficulté en probabilites est déjà repérée ; le parcours installera les notions puis un entraînement court.
  5. inequations est fragile et demande une consolidation régulière, sans reprise intégrale du cours.
  6. pourcentages est fragile et demande une consolidation régulière, sans reprise intégrale du cours.
  7. vecteurs reste non évalué ; une vérification ciblée précédera toute décision pédagogique.

Comment le diagnostic construit les cinq séances

  1. Les repères observés seront croisés avec ceux du groupe constitué afin de régler l'ordre, le temps et la profondeur du travail pendant cinq séances de deux heures. Aucun module n'est fixé avant cette lecture collective.

En synthèse

Ce parcours guidera le travail du stage et permettra d’en suivre les progrès.

« Les jeunes voyageurs avancèrent, observèrent la route et choisirent des passages étroits. »

**Critère d'attribution du point :** la réponse respecte la méthode suivante : Modifier le déterminant et le nom, répercuter les accords, puis conjuguer chaque verbe au même temps.

### Correction question 2

**Réponse : D — des histoires passionnantes**

Le déterminant, le nom et l'adjectif portent tous la marque du pluriel.

**Lecture des erreurs possibles**

- A : Une transformation au pluriel n'est pas propagée à tous les éléments du groupe.
- B : Le genre ou le nombre du nom noyau n'est pas repéré.
- C : L'accord se fait avec le mot le plus proche plutôt qu'avec le nom noyau.

**Critère d'attribution du point :** la réponse respecte la méthode suivante : Identifier le nom noyau et propager correctement genre et nombre dans le groupe nominal.

**Source :** `n05:n05-i1`

### Correction question 3

**Réponse : A — reste**

Le sujet de « reste » est le noyau singulier « liste », malgré les pluriels intercalés.

**Lecture des erreurs possibles**

- B : Le verbe est accordé avec le nom placé immédiatement avant lui.
- C : Un pronom complément est pris pour le sujet.
- D : Le sujet inversé n'est pas identifié après le verbe.

**Critère d'attribution du point :** la réponse respecte la méthode suivante : Identifier le donneur d'accord du verbe, quelle que soit sa place.

**Source :** `n06:n06-i3`
